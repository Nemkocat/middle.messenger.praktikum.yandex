# Vite Messenger

Современный мессенджер, построенный с использованием TypeScript, Vite и компонентного подхода.

## 🚀 Функциональность

- **Страница авторизации** с валидацией полей
- **Страница регистрации** с полной валидацией всех полей
- **Список чатов** с возможностью выбора чата, отображением истории чата и подсчётом непрочитанных сообщений
- **Область переписки** с отправкой сообщений (покачто вывод в терминал)
- **Профиль пользователя** с настройками (в разработке)
- **Валидация форм** в реальном времени (blur + submit)
- **Компонентный подход** с Block и EventBus 
- **TypeScript** для типобезопасности

## 🛠 Технологии

- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **Handlebars** - шаблонизатор
- **SCSS** - стилизация
- **ESLint** - линтинг TypeScript
- **Stylelint** - линтинг стилей
- **XMLHttpRequest** - HTTP запросы (без fetch/axios)

## 🚀 Установка и запуск

### Требования
- Node.js 22.18.0+
- npm 10.9.3+

### Команды

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка проекта
npm run build

# Предварительный просмотр сборки
npm run preview

# Запуск (линтеры + сборка + предварительный просмотр)
npm run start

# Линтинг TypeScript
npm run lint

# Автоисправление ESLint
npm run lint:fix

# Линтинг стилей
npm run lint:styles

# Автоисправление Stylelint
npm run lint:styles:fix
```

## 📋 Валидация

Реализована валидация для всех форм:

- **first_name, second_name** - латиница/кириллица, первая заглавная, без пробелов/цифр
- **login** - 3-20 символов, латиница, может содержать цифры, дефис, подчёркивание
- **email** - латиница, @ и точка, буквы перед точкой
- **password** - 8-40 символов, заглавная буква + цифра
- **password_repeat/confirmPassword** - проверка соответствия основному паролю
- **phone** - 10-15 цифр, может начинаться с +
- **message** - не пустое

Валидация работает на событиях `blur` и `submit`.
